# JavaReleases 📅 - Key features by version 

## Description 📄

This project includes unit tests for key functionalities introduced in each Java version.

- [Java 1.0 (Java 0)](src/test/java/pl/mperor/lab/java/Java0.java) — classes & interfaces, exceptions, threads, legacy collections, AWT
- [Java 1.1 (Java 1™)](src/test/java/pl/mperor/lab/java/Java1.java) — inner classes, JDBC, reflection, serialization, `java.text` i18n, `BigDecimal`
- [Java 1.2 (Java 2™)](src/test/java/pl/mperor/lab/java/Java2.java) — Collections Framework, Swing
- [Java 1.3 (Java 3™)](src/test/java/pl/mperor/lab/java/Java3.java) — JNDI, Java Sound, `Timer`
- [Java 1.4 (Java 4™)](src/test/java/pl/mperor/lab/java/Java4.java) — `assert`, NIO, regex, exception chaining, logging, ImageIO
- [Java 1.5 (Java 5™)](src/test/java/pl/mperor/lab/java/Java5.java) — generics, for-each, autoboxing, varargs, enums, annotations, `java.util.concurrent`
- [Java 1.6 (Java 6™)](src/test/java/pl/mperor/lab/java/Java6.java) — scripting engines, Compiler API, system tray
- [Java 1.7 (Java 7™)](src/test/java/pl/mperor/lab/java/Java7.java) — try-with-resources, multi-catch, diamond, switch on strings, NIO.2, Fork/Join
- [Java 1.8 (Java 8™)](src/test/java/pl/mperor/lab/java/Java8.java) — lambdas, functional interfaces, streams, `Optional`, `java.time`
- [Java 9™](src/test/java/pl/mperor/lab/java/Java9.java) — `List.of`/`Map.of`, private interface methods, Process API, JShell
- [Java 10™](src/test/java/pl/mperor/lab/java/Java10.java) — `var`
- [Java 11™](src/test/java/pl/mperor/lab/java/Java11.java) — HTTP Client, single-file source launch, `var` in lambdas
- [Java 12™](src/test/java/pl/mperor/lab/java/Java12.java) — JVM Constants API, switch expressions (preview)
- [Java 13™](src/test/java/pl/mperor/lab/java/Java13.java) — dynamic CDS archives, text blocks (preview)
- [Java 14™](src/test/java/pl/mperor/lab/java/Java14.java) — switch expressions, helpful NullPointerExceptions, records (preview)
- [Java 15™](src/test/java/pl/mperor/lab/java/Java15.java) — text blocks, hidden classes, ZGC & Shenandoah
- [Java 16™](src/test/java/pl/mperor/lab/java/Java16.java) — records, pattern matching for `instanceof`, `jpackage`
- [Java 17™](src/test/java/pl/mperor/lab/java/Java17.java) — sealed classes, strong encapsulation of JDK internals, new PRNGs
- [Java 18™](src/test/java/pl/mperor/lab/java/Java18.java) — UTF-8 by default, Simple Web Server, code snippets in Javadoc
- [Java 19™](src/test/java/pl/mperor/lab/java/Java19.java) — virtual threads & record patterns (preview)
- [Java 20™](src/test/java/pl/mperor/lab/java/Java20.java) — scoped values (incubator), second previews
- [Java 21™](src/test/java/pl/mperor/lab/java/Java21.java) — virtual threads, sequenced collections, record patterns, pattern matching for switch
- [Java 22™](src/test/java/pl/mperor/lab/java/Java22.java) — Foreign Function & Memory API, unnamed variables & patterns
- [Java 23™](src/test/java/pl/mperor/lab/java/Java23.java) — Markdown documentation comments
- [Java 24™](src/test/java/pl/mperor/lab/java/Java24.java) — Stream Gatherers, Class-File API, virtual threads without pinning
- [Java 25™](src/test/java/pl/mperor/lab/java/Java25.java) — scoped values, module imports, compact source files, flexible constructor bodies

For detailed examples and tests of each feature, please refer to the individual source files linked above.
